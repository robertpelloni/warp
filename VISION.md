# VISION
The ultimate goal of this project is to turn Warp into the ULTIMATE AGENTIC CODING HARNESS.
It will be a multi-language, multi-platform tool that encompasses every feature from every agentic coding harness, including:
tabby, warp, hyper, wave, codex desktop, antigravity 2.0, claude desktop, claude code, codex cli, gemini-cli, opencode, pi-mono/pi-coding-agent, hermes-agent, hermes desktop, and many more.

We aim to have 4 versions of this program that are all identical: Rust (existing), Go, C#, and Java.
Each version will have EVERY FEATURE and EVERY FUNCTIONALITY of all of these other tools.
