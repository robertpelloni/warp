# Warp: The Ultimate Agentic Coding Harness

Warp is an ambitious project aiming to combine every feature from every major agentic coding harness (tabby, warp, hyper, wave, codex desktop, claude desktop, aider, and more) into a single unified architecture.

This project is implemented identically across four languages:
- **Rust** (Native terminal environment)
- **Go** (High performance backend & CLI tool)
- **C#** (Enterprise-grade IDE integration)
- **Java** (Cross-platform enterprise compatibility)

## Getting Started
Each environment has its own root directory:
- `./` : Rust implementation
- `warp-go/` : Go implementation
- `warp-csharp/` : C# implementation
- `warp-java/` : Java implementation

## Architecture
Warp leverages a central intelligence model to coordinate tasks, featuring:
- TUI and WebUI with full feature parity.
- Deep integration with browser and IDEs.
- Local capabilities to run agents, plan, code, and review simultaneously.

## Contributions
We iteratively add submodules of other agent tools, analyze them, and rebuild their functionality natively into our four language harnesses.
